# 测试用例（论文"系统测试"一章可直接用）

- 测试环境：Windows 10/11 + JDK 17 + MySQL 8.0 + Chrome/Edge
- 测试数据：`src\db\demo-data.sql` 导入后的数据（3 位主人、6 只宠物、6 条免疫、3 条就诊、3 条寄养、3 条领养、2 条公告）
- 账号：admin / staff / owner，密码都是 `123456`
- 判定：实际结果与预期一致为"通过"
