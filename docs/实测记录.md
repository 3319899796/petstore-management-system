## 五、启动方式（本机）

```text
tools\一键启动.cmd      # 依次起 MySQL → 后端 → 前端，约 15 秒后自动开浏览器
tools\start-mysql.cmd   # 单独起数据库（窗口别关）
tools\start-backend.cmd # 单独起后端（窗口别关）
tools\start-frontend.cmd# 起前端静态服务并打开 http://127.0.0.1:5173
```

登录：`admin` / `staff` / `owner`，密码都是 `123456`。
