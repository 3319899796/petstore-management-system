# 部署与运行说明（Windows 本机版）

> 目标：在一台干净的 Windows 电脑上，按顺序做完就能打开系统。
> 后端 = Spring Boot（Java），前端 = Vue（Node 构建），数据库 = MySQL。

**为什么 MySQL 在 `D:\petstore-rt` 而不是项目目录里**：MySQL 8.0 解析配置文件里的 `basedir`/`datadir` 时不认中文路径（会截断成 `D:\`），而项目目录叫「论文毕设」。所以用一个 **目录联接（junction）** 把 `D:\petstore-rt` 指向 `D:\论文毕设\.runtime`——文件其实还在项目里，只是给 MySQL 一个纯英文的入口。`D:\petstore-rt` 不要删（删了 MySQL 启动不了），它只是个链接，不占额外空间。

### 三个一键启动脚本（在 `tools\` 下，双击即可）

| 脚本 | 作用 | 启动后 |
|---|---|---|
| `tools\start-mysql.cmd` | 启动数据库 | 弹出一个窗口，看到 `ready for connections` 就成了 |
| `tools\start-backend.cmd` | 启动后端 | 看到 `Tomcat started on port(s): 8080` |
| `tools\start-frontend.cmd` | 启动前端并打开浏览器 | 浏览器自动打开 `http://127.0.0.1:5173` |
| `tools\一键启动.cmd` | 依次启动上面三个 | 等 15 秒左右浏览器就打开了 |

顺序不能颠倒：**数据库 → 后端 → 前端**。关掉窗口就等于停止服务。

## 1. 装三个工具

### 1.1 Maven 3.9（把 Java 代码编译成可运行的 jar）

1. 打开 https://maven.apache.org/download.cgi ，下载 `apache-maven-3.9.x-bin.zip`
2. 解压到 `C:\dev\apache-maven-3.9.9`（路径别带空格和中文）
3. 设置环境变量（PowerShell 里执行，永久生效）：
   ```powershell
   [Environment]::SetEnvironmentVariable('MAVEN_HOME','C:\dev\apache-maven-3.9.9','User')
   $p = [Environment]::GetEnvironmentVariable('Path','User')
   [Environment]::SetEnvironmentVariable('Path', "$p;C:\dev\apache-maven-3.9.9\bin", 'User')
   ```
4. **关掉 PowerShell 再重新打开**，执行 `mvn -v`，看到 `Apache Maven 3.9.x` 和 `Java version: 17` 就成功。

> 第一次构建会从网上下载依赖（约 100MB），国内建议在 `C:\Users\<你>\.m2\settings.xml` 里加阿里云镜像（项目 `pom.xml` 里已经配了阿里云仓库，通常不用额外配）：
> ```xml
> <settings>
>   <mirrors>
>     <mirror>
>       <id>aliyunmaven</id>
>       <mirrorOf>*</mirrorOf>
>       <url>https://maven.aliyun.com/repository/public</url>
>     </mirror>
>   </mirrors>
> </settings>
> ```

### 1.2 MySQL 8.0（存数据）

1. 打开 https://dev.mysql.com/downloads/installer/ ，下载 `mysql-installer-community-8.0.x.msi`
2. 安装时选 **Server only** 或 **Custom → MySQL Server 8.0 + MySQL Workbench**
3. 配置页注意两点：
   - Authentication Method：选 **Use Strong Password Encryption**（默认即可）
   - Root Password：设成 `123456`（与项目默认配置一致；想用别的密码见 2.3）
4. 安装完确认服务在跑：
   ```powershell
   Get-Service MySQL80
   ```
   状态应为 `Running`。若没有，执行 `Start-Service MySQL80`。

### 1.3 Node.js 18+（只在要构建前端时需要）

1. https://nodejs.org/ 下载 LTS 版 `.msi` 安装（一路下一步）
2. 重开 PowerShell，`node -v` 与 `npm -v` 都要有版本号
3. 建议加国内镜像（下载快很多）：
   ```powershell
   npm config set registry https://registry.npmmirror.com
   ```

## 5. 生产式部署（可选，答辩不需要，但论文"系统部署"一节可以写）

推荐单机部署：**Nginx 托管前端静态文件 + 反向代理 `/api` 到后端 jar**。

1. 后端打成 jar，放在 `D:\petstore\pet-store-backend-1.0.0.jar`
2. 用 NSSM（https://nssm.cc/）把它注册成 Windows 服务，开机自启：
   ```powershell
   nssm install PetStoreBackend "C:\Program Files\Java\jdk-17\bin\java.exe" "-jar D:\petstore\pet-store-backend-1.0.0.jar"
   nssm start PetStoreBackend
   ```
3. Nginx 配置：
   ```nginx
   server {
       listen 80;
       server_name localhost;
       root D:/petstore/dist;
       index index.html;

       location / {
           try_files $uri $uri/ /index.html;   # Vue 单页应用必须这样配，否则刷新 404
       }
       location /api/ {
           proxy_pass http://127.0.0.1:8080/api/;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           client_max_body_size 10m;           # 允许上传宠物照片
       }
   }
   ```

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报 `Communications link failure` | MySQL 没启动 / 端口不通 | `Get-Service MySQL80`，`Start-Service MySQL80` |
| 启动报 `Access denied for user 'root'` | 密码不对 | 改 `application.yml` 的 password 或设 `MYSQL_PASSWORD` |
| 启动报 `Unknown database 'pet_store'` | 没执行 schema.sql | 回到 2.1 |
| 登录返回「账号或密码不正确」 | 没启动过带 `DataInitializer` 的版本，用户表是空的 | 正常启动后端一次，控制台会打印三个演示账号已创建 |
| 前端页面空白、控制台 401 | 后端没启动，或 token 过期（2 小时） | 重新登录 |
| 上传照片成功但显示不出来 | 后端没正常返回 `/files/...`，或 `app.upload.dir` 目录不存在 | 后端会自动建目录；照片地址要拼 `http://127.0.0.1:8080/api` 前缀 |
| `mvn` 不是命令 | 环境变量没生效 | 关掉 PowerShell 重开，或 `C:\dev\apache-maven-3.9.9\bin\mvn.cmd` |
| 前端 `npm install` 卡住 | 默认源慢 | `npm config set registry https://registry.npmmirror.com` |
