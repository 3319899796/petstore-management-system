# 接口清单（后端已实现，前端按此对接）

统一约定：

- 基础地址：`http://127.0.0.1:8080/api`
- 除登录外所有接口都要请求头 `Authorization: Bearer <token>`
- 返回统一结构：`{"code":200,"message":"成功","data":...}`；`code != 200` 时 `message` 是可直接展示给用户的中文提示
- 分页参数：`pageNum`（默认 1）、`pageSize`（默认 10，上限 100）、`keyword`
- 分页返回：`data = { total, records: [] }`
- 日期格式：日期 `yyyy-MM-dd`，时间 `yyyy-MM-dd HH:mm:ss`

## 1. 认证 `/auth`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/auth/login` | 匿名 | body `{username,password}` → `{token,userId,username,roleId,roleName,permissions:[],expiresIn}` |
| GET | `/auth/me` | 登录 | 当前登录信息 |
| POST | `/auth/logout` | 登录 | 无状态，前端清 token 即可 |

## 2. 宠物档案 `/pet`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/pet/page` | pet:list | 参数 `petId?` 无；支持 `keyword`（宠物名/芯片号）、`ownerId`、`breed`；主人角色自动只看自己的 |
| GET | `/pet/options` | pet:list | 下拉用 `[{petId,petName,ownerId,ownerName}]` |
| GET | `/pet/{petId}` | pet:view | 详情（越权 403） |
| POST | `/pet` | pet:add | body `{petName,chipNo,breed?,ownerId,photoPath?}` |
| PUT | `/pet` | pet:edit | 同上 + `petId`；主人不能改 ownerId |
| DELETE | `/pet/{petId}` | pet:delete | 被免疫/就诊等引用时返回 400「该数据已被其它记录引用」 |
| POST | `/pet/upload` | pet:add 或 pet:edit | `multipart/form-data`，字段名 `file` → 返回路径字符串 `/files/2026/11/xxx.jpg`，前端显示时拼 `http://127.0.0.1:8080/api` + 路径 |

## 3. 主人档案 `/owner`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/owner/page` | owner:list | `keyword`（姓名/手机号） |
| GET | `/owner/options` | owner:list | 下拉用 |
| GET | `/owner/me` | 登录 | 主人查自己档案（拿 ownerId），未绑定返回 400 提示 |
| POST | `/owner` | owner:edit | `{ownerName,phone?,userId?}` |
| PUT | `/owner` | owner:edit | 同上 + `ownerId` |
| DELETE | `/owner/{ownerId}` | owner:edit | 名下有宠物时拒绝 |

## 4. 免疫记录 `/vaccine`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/vaccine/page` | vaccine:list | `petId?`、`dueSoon=true`（7 天内到期 + 已逾期，按到期日升序） |
| GET | `/vaccine/pet/{petId}` | vaccine:list | 宠物详情页用 |
| GET | `/vaccine/upcoming?days=7` | vaccine:list | 看板用 |
| POST | `/vaccine` | vaccine:add | `{petId,vaccineType,inoculateDate,nextDueDate?,cycleDays?}`；nextDueDate 留空则按 cycleDays（默认 365）自动算 |
| PUT | `/vaccine` | vaccine:edit | 同上 + `vaccineId`；到期日变了会重置提醒标记 |
| DELETE | `/vaccine/{vaccineId}` | vaccine:edit | |

返回项含 `daysLeft`（0=今天到期，负数=已逾期，前端据此标红）。

| GET | `/medical/pet/{petId}` | medical:list | |

## 6. 寄养 `/foster`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/foster/page` | foster:list | `petId?`、`status?` |
| POST | `/foster` | foster:add 或 foster:audit | `{petId,startDate,endDate}` → 生成 PENDING |
| PUT | `/foster` | 同上 | 仅 PENDING 可改 |
| POST | `/foster/audit` | foster:audit | `{id,approved,reason?}`；驳回必须填 reason |
| POST | `/foster/{fosterId}/finish` | foster:audit | APPROVED → FINISHED |
| DELETE | `/foster/{fosterId}` | foster:add/audit | 仅 PENDING/REJECTED 可删 |

状态：`PENDING 待审核 → APPROVED 寄养中 → FINISHED 已结束`；`PENDING → REJECTED 已驳回`。

## 7. 领养 `/adoption`

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/adoption/page` | adoption:list | `petId?`、`status?`；主人只看自己提交的 |
| POST | `/adoption` | adoption:add | `{petId}`；不能申请自己名下的宠物 |
| POST | `/adoption/audit` | adoption:audit | `{id,approved,reason?}`；通过即把 pet.owner_id 改成申请人 |
| POST | `/adoption/followup` | adoption:followup | `{adoptionId,followUpResult}`；仅 APPROVED 可回访 |
| DELETE | `/adoption/{adoptionId}` | adoption:add/audit | 仅 REJECTED 可删 |
